Build order

  1. Database and login first. Everything else depends on them, and both already run in the first commit.
  2. Authors and categories, because the book forms need their dropdowns.
  3. Books and members side by side.
  4. Issuing, then returns. Both need real books and members.
  5. Dashboard, layout and rule testing throughout, with a full pass at the end.
  6. Fresh XAMPP test, report and demo rehearsal.

Working rules

  • Commit from your own GitHub account, in small steps. The brief marks regular commits from every member.
  • Work on a branch named after your area, such as books, and open a pull request to main.
  • Copy the pattern in authors/index.php for new pages. Replace the "Not built yet" box when you build a page.
  • Learn more than your own part. Any member can be asked to explain any code, and a member who can't is marked down individually.
  • Write one report paragraph for your part, plus your screenshots, and give them to Antonia Nyakato.
